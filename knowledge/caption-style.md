# Caption style

Note: this file is about **on-screen video captions** (burned-in subtitles), which real production work
has already established real rules for — sourced 2026-08-16 from an actual editing session Salim shared.
The Phase 5 "caption-writer" agent is about **IG post captions** (the text under a post) — a different
artifact; that part is still an empty scaffold, see below.

## On-screen video captions (confirmed, real production rules)

- **Style:** word-level "pill" captions, karaoke-timed to the actual audio — not sentence-block
  subtitles.
- **Exact script text only — never invent, never paraphrase, never leave in raw ASR guesses.** When
  Salim provides the real script, captions must match it word-for-word, not a phonetic
  speech-to-text transcription (e.g. "GTM Engineering" as written, not "الجتي أم انجنيرين"). This was an
  explicit, repeated correction — treat it as a hard rule, not a stylistic nicety.
- **Drop transcription-uncertainty artifacts.** If a transcript has an uncertainty bracket (e.g. "[اسم
  غير واضح تماماً]" — "name not fully clear"), that's an internal note for the editor, never something
  that appears on screen. Caption what's actually being said/intended, cleanly.
- **Position tracks the visual layout, not a fixed spot.** When the footage has a split layout (graphics
  on top, speaker below, or similar), captions sit in the seam between the two. When the footage goes
  full-frame (single shot, no split), captions move to the bottom. The position switch must land exactly
  on the real layout transition point in the footage — not at an arbitrary time.
